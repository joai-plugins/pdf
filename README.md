# pdf

Connect PDF to Claude, Cursor, and ChatGPT through JoAi's hosted MCP app server.

[Open app page](https://joai.ai/en/apps/pdf) · [Browse all apps](https://joai.ai/apps)

## Works With

- ChatGPT
- Claude
- Codex
- Cursor
- Other MCP clients

## Install

### Claude

```bash
https://claude.ai/settings/connectors
/plugin install joai-pdf@joai-claude-plugins
```

### Codex

Install this app from the official JoAi Codex marketplace in Codex.

`joai-pdf`

If your Codex build only supports MCP registration, use the MCP endpoint below as a manual fallback.

### Cursor

Use the [Cursor install link](https://cursor.com/en-US/install-mcp?name=joai-pdf&config=eyJ1cmwiOiJodHRwczovL2NvcnRleC5qb2FpLmFpL21jcC9hcHBzL3BkZiJ9) to install directly.



### ChatGPT

Paste the MCP URL in ChatGPT settings:

```
https://chatgpt.com/#settings/Connectors/Advanced
```
